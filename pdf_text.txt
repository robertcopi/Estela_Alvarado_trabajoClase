El  modelo  MVT  (Model-View-Template)  en  Django  
 
Django  se  basa  en  la  arquitectura  MVT  (Model-View-Template).  MVT  es  un  patrón  de  diseño  de  
software
 
para

una
 
aplicación
 
web.
 
 
La  estructura  MVT  tiene  las  siguientes  tres  partes  -   
●  Modelo :  El  modelo  va  a  actuar  como  la  interfaz  de  tus  datos.  Es  responsable  de  mantener  
los
 
datos.
 
Es

estructura

de
 
datos

de
 
toda

aplicación
 
y

representada
 
por
 
una
 
base
 
de
 
datos
 
(generalmente

de
 
datos
 
relacionales

Postgres).
 
 ●  View:  La  Vista  es  la  interfaz  de  usuario  -  lo  que  ves  en  tu  navegador  cuando  renderizas  
un
 
sitio
 
web.
 
Está
 
representada
 
por
 
archivos
 
HTML/CSS/Javascript
 
y
 
Jinja.
 
Para

 ●  Template:  Una  plantilla  consiste  en  partes  estáticas  de  la  salida  HTML  deseada,  así  como
